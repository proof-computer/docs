# Get started

You do not need to understand Acurast or confidential computing before your
first launch. Start with the path that matches what you want to run; the docs
introduce the underlying model when it becomes useful.

1. [Choose Marketplace or GitHub](./choose-your-path.md).
2. [Set up Liskov](./set-up-liskov.md) with a GitHub identity, organization,
   plan, and USD Service Credits.
3. Complete [Launch from Marketplace](./marketplace.md) or
   [Deploy from GitHub](./github.md).
4. [Follow your first deployment](./first-deployment.md) and verify its result.

Marketplace is the shorter path. GitHub adds repository preparation, a strict
Application Manifest V4, and build provenance.

After your first success, continue to [Deploy & operate](../operate/index.md)
or learn [how Liskov works](../concepts/how-liskov-works.md).
